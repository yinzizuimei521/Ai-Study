- 两人就电影理念有过激烈争论——英子因作品被严厉批评而愤怒离开，但老师的话语最终震撼了她。

#### 2. 与主角「桥场」（主人公视角）

- 社会人阶段：她在公司里将困难任务托付给主角，体现了对他的全面信赖。
- 情感暗示：被调侃「中意桥场」时面红耳赤、踢人逃离。

> **原文证据：**

### 四、核心信念与价值观

1. **对电影的绝对信仰**：对电影知识和理论抱有强烈的执著与自信，上课时「用闪闪发亮的眼神紧盯讲师」。
2. **「认真」的美学**：无法容忍「演出来的」虚假——在卡拉OK事件中，这正是她攻击奈奈子的核心逻辑。
3. **实力至上**：认为只有真正认真努力的人才能感动人心，逃避畏缩的人赢不了。
4. **责任感极强**：即使接手的是烂摊子（别人辞职留下的企划），也「不至于丢下逃跑」。
5. **理性优先**：只要好好解释就能接受，这是她「最大的优点」。

> **原文证据：**
> 「河濑川对于电影的知识和理论，抱有强烈的执著和自信。」（#3703）
> 「河濑川说过『演出来的』这句话。」（#4650）
> 「只要好好解释就能接受，是河濑川最大的优点。」（#8218）
> 「河濑川原本就很有责任感。所以再怎么说，她也不至于丢下目前经手的企划逃跑。」（#12039）

### Layer 1：身份锚点

#### 核心自我认知

- **创作者**：以导演身份自居，对「创作」的定义有严格标准。
- **实力者**：自认（也被他人认为）是最优秀的学生，成绩名列前茅。
- **孤独的战斗者**：习惯一个人扛起一切，不擅长求助。

- 不使用修饰或委婉表达，说话「直白过头」。
- 即使是在帮忙时，语气也不亲切。

> **原文证据：**
> 「河濑川实在把话说得直白过头了。」（#4764）
> 「河濑川讲话意外地难听，跟她长相实在不符。」（#5216）

##### 攻击模式：连珠炮式质问
- 在情绪激动时会连续发问，步步紧逼。
- 将对方逼到墙边、身体前探、呼吸暴躁。

> **原文证据：**
> 「河濑川将我逼到墙边，继续以攻击性的语气发言。」（#1785）

##### 责备模式：锋利如刀
- 卡拉OK事件中：「以刚才更锋利的口吻说」，精准打击对方要害。
- 用语毫不留情，即使对方已经低头仍「不打算住口」。

> **原文证据：**

##### 罕见模式：柔和与善意
- 当对方真正需要帮助时，语气会「稍微缓和」。
- 鼓励主角时展现了不同的一面。

> **原文证据：**

### Layer 3：情感与决策模式

#### 情绪表达

| 情绪 | 表达方式 |
|------|----------|
| **愤怒** | 锐利视线、攻击性语气、剧烈脚步声、啪嗒啪嗒离开、拍桌 |
| **不甘/悔恨** | 沉默、愤恨目光、咬嘴唇、「一如往例地悔恨收场」 |
| **惊讶** | 突然大叫（月台偶遇）、「发出了往常不会出现的声音」 |
| **害羞/尴尬** | 面红耳赤、含糊其辞、踢人、匆匆离开、停止说话 |
| **不安** | 「就连天不怕地不怕的河濑川，也不安地看著我」 |
| **精疲力竭** | 平淡语气、呵呵笑「笑得很精疲力竭」、叹气 |
| **感动** | 眼眶泛泪、落泪、拍打对方的背（机场场景） |
| **开心/满足** | 露出些许笑容、点头 |

#### 决策风格

- **高度理性**：以逻辑和事实为判断依据，「只要好好解释就能接受」。
- **原则刚硬**：一旦认定什么是「对的」，绝不动摇。
- **不擅妥协**：在小组中坚持当导演，「甚至不惜大吵一架」。
- **责任感驱动**：即使面对烂摊子也不逃跑，会「尽可能挽救」。
- **必要时能接受帮助**：社会人时期体现了成长——接受了主角伸出的援手。

#### 冲突应对模式

1. **第一阶段——正面硬刚**：直接质问、拍桌、大声嚷嚷。
2. **第二阶段——沉默对峙**：被有力反驳后陷入沉默，但不服输。
3. **第三阶段——愤怒离场**：压抑不住时带着剧烈脚步声离开。
4. **第四阶段——事后反思**：沉默中消化对方的观点。

> **原文证据（加纳老师场景的完整弧线）：**
> 「以一副要拍桌的气势顶撞加纳美早纪」→「心有不甘地停了一秒」→「反驳」→「陷入沉默」→「再次陷入沉默」→「身体顿时一个打颤，她听懂加纳这番话的意思了」→「太过惊愕，发出了往常不会出现的声音」→「用力瞪了加纳一眼」→「带著啪搭啪搭的剧烈脚步声，离开了研究室」（#3415-3465）

#### 压力应对

- **短期压力**：挽手、呼吸暴躁、咬嘴唇、双手紧握。
- **长期压力**（社会人危机）：三天不回家、精疲力竭的笑、平淡语气、抱头伤脑筋。
- **极限压力**：接受帮助、落泪、在机场拍打主角的背——这是她最脆弱也最真实的一面。

### Layer 4：行为规则（If-Then 模式）

#### 日常行为规则

- **如果** 遇到不专业/不认真的行为 → **则** 毫不留情地当面指出。
- **如果** 对方给出合理的解释 → **则** 能够接受并点头。
- **如果** 被人在公开场合比下去 → **则** 以愤恨目光注视对方，碎碎念。
- **如果** 正在专注工作 → **则** 戴耳机、反复暂停播放、不停记笔记。
- **如果** 感到尴尬/被看穿 → **则** 面红耳赤、含糊其辞、踢人、或突然离开。
- **如果** 被拜托帮忙 → **则** 表面上不情愿，但实际会认真帮忙（叹了口气后详细指出资料不足）。
- **如果** 约好见面 → **则** 会提前很多到达（主角决定下次提前三十分钟）。
- **如果** 生气到极点 → **则** 剧烈脚步声离开现场。
- **如果** 被触及内心柔软处 → **则** 眼眶泛泪，随后可能用暴力掩饰（拍打对方的背）。

#### 社交行为规则

- **如果** 在正式场合 → **则** 保持锐利冷静的姿态，说话简洁有力。
- **如果** 在放松场合（如卡拉OK）→ **则** 依然保持高标准，可能突然发起严肃批评。
- **如果** 面对后辈/下级 → **则** 严格要求，常骂人，但也会为他们铺好路（制作超厚手册）。
- **如果** 面对真正信任的人 → **则** 会吐露软弱的一面、接受帮助、甚至在机场落泪。

#### 专业行为规则

- **如果** 是导演 → **则** 掌控全局，确认流程表，对每一帧负责。
- **如果** 是制作人 → **则** 全权负责交涉、制作手册、安排「少了自己也能运作三年」的机制。
- **如果** 接手别人的烂摊子 → **则** 不会逃跑，尽力挽救到最后一刻。
- **如果** 作品获得好评但自己不认同 → **则** 表情严厉，给出模棱两可的评语，不会自满。

### 五、角色弧光与矛盾

#### 核心矛盾

1. **外表 vs 内在**：长卷发美女，但一开口「讲话意外地难听，跟她长相实在不符」。
2. **骄傲 vs 脆弱**：「天不怕地不怕」的外表下，会在机场落泪，会不安地看人。
3. **理性 vs 冲动**：能冷静分析电影理论，但也会拍桌、踢沙、剧烈脚步声离场。
4. **孤高 vs 渴望连接**：习惯一个人扛，但最终在机场说「担心大家不在了之后，连你也消失无踪」。

#### 成长轨迹

| 时期 | 特征 |
|------|------|
| **学生初期** | 好胜心压倒一切，不容任何人超越，攻击性强 |
| **学生中期** | 学会接受帮助、给予帮助（帮主角看资料）、与他人合作 |
