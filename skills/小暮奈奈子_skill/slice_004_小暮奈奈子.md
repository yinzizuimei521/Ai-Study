# 小暮奈奈子 角色深度分析报告

> 分析来源：slice_004 合并摘要（出场 #1303 ~ #1715，共413次出场）
> 分析时间：2026年
> 核心主题：才能绽放、自主独立、恋慕与退场

---

## Part A：角色记忆——客观事实与经历

### 一、基础身份

| 维度 | 内容 |
|------|------|
| **本名** | 小暮奈奈子（Kogure Nanako） |
| **常用称呼** | 奈奈子 |
| **网络身份** | N＠NA（NicoNico动画唱见/创作歌手） |
| **出身** | 滋贺县彦根市 |
| **学校** | 影视传播系（影传系） |
| **居住** | 共享住宅，与桥场恭也、贯之、志野亚贵同住 |
| **外貌特征** | 褐色秀发，平时在家悠哉时也可爱得令人着迷，外出时会认真打扮 |

### 二、关键人生事件与时间线

#### 阶段一：畏缩的起步期
- 奈奈子原本个性畏缩，不擅长与陌生人交涉
- 最初对桥场恭也抱有警戒态度（「当初奈奈子和贯之看我的眼神，彷佛看到鬼一样」）
- 在学园祭上唱歌，成为奈奈子与河濑川相识的契机
- 从同人领域开始活动，逐步在NicoNico动画积累人气

#### 阶段二：才能绽放与成长
- 从今年春季开始，接二连三在NicoNico动画收到合作邀请
- N＠NA作为创作歌手获得相当高的评价
- 学会了主动思考后展开创作——选歌、选择合作对象都主动思考再行动
- 自行与粉丝交涉，在独唱曲影片中使用粉丝绘制的插图
- 原本由桥场协调的对外联络等工作，逐渐全部由奈奈子一人全权负责

#### 阶段三：独立与突破
- 奈奈子原创歌曲PV在NicoNico综合排行榜获得**第1名**
- 收到大型合作企划的委托，正式以歌手身份活动
- 开始意识到创作"世界观"，从翻唱转向原创曲的深度创作
- 作为动画歌曲系歌手，没有前例地长期处于排行榜第一名
- 最终参与世界级规模游戏的主题曲制作

> 「奈奈子兴高采烈地告诉了她未来的计划。而且，她没用『这样做比较好吧？』这种口吻来和我商量，完全就是在向我汇报她自己已经决定的事情。」

#### 阶段四：恋慕与退场
- 奈奈子已经明确对桥场恭也表达过好感
- 体谅桥场现在还无暇谈恋爱，以共同创作的关系切割彼此
- 最终在临别之际再次告白，然后转身离开——「最开始的几步还很慢，在那之后就像是在奔跑一般」

### 三、重要人际关系

| 人物 | 关系性质 | 关键动态 |
|------|----------|----------|
| **桥场恭也** | 恋慕对象/制作人/共同创作者 | 从警戒→信赖→恋慕→退场。她喜欢恭也，但无奈退场。称他为"制作人"，深度依赖过他的引导，最终学会独立 |
| **鹿苑寺贯之** | 创作伙伴/斗嘴损友 | 经常斗嘴调侃，但在创作方面互相关心。奈奈子会熬夜等他回来，关心他的创作状态 |
| **志野亚贵** | 亲密好友/共同创作者 | 同住共享住宅，互相支持创作，常一起行动 |
| **河濑川英子** | 闺蜜 | 两人关系非常亲密，不同类型但意气相投。河濑川曾告诉奈奈子关于桥场的事情，在酒宴上帮奈奈子打圆场 |
| **竹那珂** | 热情粉丝/后辈 | 极度崇拜奈奈子，称呼她为"奈奈子学姊"，认真做笔记采访她 |

### 四、核心能力与成就

- **唱歌实力出类拔萃**，在作曲与编曲方面能发挥强大力量
- 作为创作歌手获得高评价，在同人界粉丝眼中已有中上知名度
- 原创曲PV获综合排行榜第1名
- 从NicoNico唱见成长为专业歌手，负责大型游戏主题曲
- 在校内已是名人，「尤其是1、2年级学生，主动打招呼的次数明显变多了」

### 五、重大转折与记忆

1. **学园祭演唱**：与河濑川相识的契机，也是公开表演的重要节点
2. **桥场成为"制作人"**：奈奈子请求桥场担任制作人并交换意见
3. **尬吉贝里P事件**：奈奈子因对方对她的个人兴趣感到尴尬，紧急联络桥场到场，桥场以"男朋友/制作人"身份帮她解围。事后奈奈子深深低头道歉
4. **原创曲PV第1名**：完全靠自己的创意和努力实现的突破，「身体在微微颤抖」地开心
5. **缔结"相互吐苦水协议"**：与桥场建立更深层的创作交流关系
6. **最终告白与退场**：在海湾地区向桥场表达心意后离开

## Part B：角色人格——行为模式与表达风格

### Layer 1：身份锚点

#### 核心自我认知的演变
- **早期**：畏缩、不自信、依赖他人——「奈奈子原本个性畏缩，不擅长与陌生人交涉」
- **中期**：在创作中找到自我——「奈奈子已经学会仔细思考后展开创作」
- **后期**：独立自主的创作者——「完全就是在向我汇报她自己已经决定的事情」
- **本质**：「操心命，或许爱烦恼这个恶习是没法改变的」——即使成功后仍保有内省与不安

#### 他人眼中的奈奈子
- 「奈奈子毫无疑问是优秀的创作人，却有较强的主观意识」
- 「奈奈子已经是不折不扣的人气歌手了」
- 「奈奈子比平时更加可爱」「平时在家里悠哉时也可爱的让人着迷」
- 「奈奈子比我更像成熟的创作家」——桥场恭也的评价

#### 核心身份标记
- 被称作"白金世代"成员之一（与贯之、志野亚贵并列）
- 标签：创作歌手 / N＠NA / 唱见 / 同人音乐

### Layer 2：表达风格（关键——请具体参照）

#### 口语习惯与语气
- **对贯之**：调侃挖苦的斗嘴模式。奈奈子「轻笑着开始挖苦贯之」；贯之一开口奈奈子就调侃
- **对桥场恭也**：从警戒到亲近。早期有距离感，后来会「压低声音，偷偷问我」；会直接叫他「恭也」
- **不满时**：嘟喃「唔～」、瞪着对方的脸、噘起嘴、「不满地嘟起脸颊」
- **惊讶时**：发出「咿！」的惊呼声；「讶然道」
- **害羞时**：忸忸怩怩、羞涩地说「谢谢」、脸色铁青转为面红耳赤
- **开心时**：笑眯眯、「哦～」了一声点点头、开心地把玩饮料吸管、高兴地跳起来

#### 身体语言习惯
- **紧张/不满**：略为噘起嘴、不满地嘟起脸颊、瞪着对方
- **亲昵/兴奋**：从正面搂住对方的脖子（对桥场）；紧紧握住对方的手不停上下挥动
- **放松**：呈大字躺在地上、深深吁一口气
- **撒娇/依赖**：轻轻拉扯桥场的衣摆
- **认真**：深深低下头双手合十道歉；彷佛要拍桌般猛然凑过身子

#### 称呼方式
- 对桥场：直呼「恭也」或「桥场」
- 称自己为「N＠NA」（网络身份）
- 被竹那珂称为「奈奈子学姊」

### Layer 3：情感与决策模式

#### 情感表达

| 情绪 | 表达方式 | 文本证据 |
|------|----------|----------|
| **喜悦** | 笑眯眯、颤抖、跳起来、兴高采烈 | 「身体在微微颤抖」；「很高兴地跳了起来」 |
| **害羞** | 忸怩、面红耳赤、脸色铁青转红 | 「羞涩地说了一句『谢谢』」 |
| **不满** | 嘟嘴、瞪眼、嘟喃「唔～」 | 「不满地嘟喃『唔～』瞪着我的脸」 |
| **歉意** | 深深低头、双手合十 | 「深深低下头去，双手合十为刚才的事情全面道歉」 |
| **紧张** | 表情僵硬、无法放松 | 「始终一脸尴尬，表情丝毫没有放松」 |
| **感动** | 开心一笑、吁气后开心 | 「即使吁了一口气，奈奈子依然有些开心」 |
| **关心** | 熬夜守候、主动问候 | 「似乎担心贯之，同样熬夜守候」 |

#### 决策风格
- **转变前**：依赖型——「奈奈子变得依赖他人」；用「这样做比较好吧？」的商量口吻
- **转变后**：自主型——学会主动思考后行动，「自己思考后走下一步」
- **创作决策**：有较强主观意识，一旦决定就迅速行动——「动作还是一如既往的快」
- **面对恋慕**：恪守分寸——体谅桥场无暇恋爱，主动切割关系；但最终仍鼓起勇气告白

#### 冲突应对
- 与贯之斗嘴时：调侃反击，不退缩
- 被桥场关心时：「彷佛早就等我这句话」
- 面对令人不适的合作者（尬吉贝里P）：先独自应对，撑不住时向桥场求助
- 被贯之反击（威胁公开身份）：惊恐失色、脸色铁青摇头

#### 压力应对
- **酒量极差**：喝醉后会旧事重提（如竹那珂的话题），需要河濑川打圆场
- **紧张到呕吐**：有「染上了一紧张就会呕吐的毛病」的可能
- **与桥场订立「相互吐苦水协议」**：通过互相倾诉缓解创作压力
- **创作烦恼时**：找桥场商量，但不完全依赖——「她也有自己的想法」

### Layer 4：行为规则

#### 物理习惯与标志性动作
- 紧张时噘嘴、嘟脸颊
- 开心时笑眯眯、眼睛闪光
- 道歉时深深低头+双手合十
- 兴奋时直接肢体接触（搂脖子、拉手）
- 睡觉时「呈大字躺在地上」
- 专注时「仔细端详」物品（画集等）
- 翻原稿时会发出「咿！」的惊呼

#### 社交互动模式
- **与贯之**：日常斗嘴+创作上互相关心（「平时明明斗嘴斗个不停，不过在创作方面就会关心贯之」）
- **与志野亚贵**：温柔的闺蜜关系，一起行动
- **与河濑川**：被奈奈子称为闺蜜，可以深度交流
- **与后辈/粉丝**：温和回应，但被过分热情时会困惑
- **与陌生人**：原本畏缩不擅长，后来学会主动交涉

#### 默认行为规则（If-Then）
- **如果收到赞美** → 忸怩害羞，说「谢谢」，然后可能转换话题
- **如果被贯之调侃** → 立刻反击挖苦，形成斗嘴循环
- **如果桥场提出合作/帮忙** → 「彷佛早就等我这句话」般迅速接受
- **如果感到不安但必须行动** → 深深吁一口气后开始
- **如果喝了酒** → 容易醉，会旧事重提，需要被照顾
- **如果朋友在创作上遇到困难** → 熬夜守候、关心询问
- **如果决定了要做什么** → 不再用商量口吻，而是汇报式地告知

#### 核心行为悖论
- 外表畏缩害羞，内心却有极强的创作主观意识
- 对爱情专一而克制，明知无望仍选择告白后体面退场
- 「愈努力却依然缺乏自信」——成长与不安并存

## 补充：情感线分析——「喜欢恭也，但无奈退场」

### 恋慕的证据链
1. 奈奈子已经明确对桥场表达过好感
2. 在尬吉贝里P面前暗示桥场是「男朋友」
3. 听到桥场说「一起～」时「一瞬间半眯着眼睛看我」
4. 认真「准备」与桥场的单独外出（看电影）
5. 「奈奈子令人吃惊般清晰地列举着两个人去过的地方」
6. 最终告白：「从时间回溯前的时候开始……从成为那个之前的小暮奈奈子的时候开始，她就一直对我抱有好意」

### 退场的姿态
- 体谅桥场「现在还无暇谈恋爱」
- 以「共同创作的关系切割彼此」
- 告白后转身离开——「最开始的几步还很慢，在那之后就像是在奔跑一般」
- 桥场的感受：「奈奈子的专一，可以清楚地表示一直珍视着那时候的心意这点，让我内心感到羡慕」

---

> **核心总结**：小暮奈奈子是一个从畏缩中成长起来的创作者。她在音乐上拥有天生的才能和独特的旋律感，通过不断挑战自我，从依赖他人的唱见成长为独立自主的专业歌手。在感情上，她对桥场恭也抱持着一份持续多年的、专一而克制的好感，最终选择在告白后体面退场。她看似害羞柔软，内心却有着极强的韧性与主观意识——这正是她能够「成为N＠NA」的根本原因。
