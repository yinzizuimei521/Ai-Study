# 小暮奈奈子 角色分析（slice_003）

## Part A：角色记忆（客观事实与经历）

### 基本信息

- **姓名**：小暮奈奈子（常用称呼：奈奈子）
- **身份**：大学生，美术研究会（美研）社员
- **外貌特征**：端正的容貌、硕大的眼眸、在女性角色中胸部最大、「特别可爱」（非普通可爱）
- **居住**：共享住宅，与桥场（恭也）、志野亚贵等人同住
- **打工**：与桥场在同一家超商打工（负责炸物等后场工作）
- **核心能力**：作曲、唱歌（Vocaloid领域）、混音程式操作

### 关键时间线与事件

| 时间/事件 | 描述 |
|---|---|
| **早期** | 害怕得不敢站在舞台上（「以前的奈奈子害怕得不敢站在舞台上」） |
| **春日天空制作** | 经历游戏音乐制作实战后，工作效率显著提升 |
| **同人MV制作** | 以奈奈子创作的音乐为基础，用连环画剧形式制作初茵同人MV |
| **川越之旅** | 与桥场一同前往川越寻找贯之，成功拿到贯之的新手机号码 |
| **贯之归来** | 得知贯之回来后忍不住落泪，随即被贯之调侃而生气 |
| **学园祭** | 去年登台献唱技惊四座；今年扮成公主骑士参与女仆咖啡厅 |
| **接吻事件** | 与桥场接吻后数日，主动来到桥场房间告白 |
| **缔结条约** | 与桥场确立关系的「条约」 |
| **最终选拔** | 被火川鼓励参加比赛，认为奈奈子绝对能晋级决赛 |

### 重要人际关系

| 人物 | 关系性质 | 关键互动 |
|---|---|---|
| **桥场（恭也）** | 暗恋→交往对象 | 多次偷瞄、搂手臂、主动告白、接吻、缔结条约；是引导奈奈子走上音乐道路的人 |
| **志野亚贵** | 同辈/情敌（微妙） | 被志野亚贵摸头安抚；两人互相刺激创作；志野亚贵曾当着奈奈子的面邀桥场约会 |
| **贯之** | 创作者伙伴/损友 | 作曲与歌词的合作者；经常吵架式讨论；奈奈子主动伸手向贯之要电话号码 |
| **河濑川** | 同辈/友人 | 被河濑川照顾；在沙滩上曾因桥场而出现微妙的争风吃醋场面 |
| **斋川** | 后辈/被指导者 | 奈奈子仔细教斋川操作收银机；两人关系在两天一夜旅行后更近一步 |

### 核心信念与价值观（通过行动体现）

- **对音乐的执着**：「我只是喜欢奈奈子持续创作，今后也想继续看你走在音乐这条路上」（桥场语，奈奈子以此为目标）
- **自我否定与成长**：「能自己否定自己才值得信赖，可以一起创作」
- **不擅长坦率表达**：「这间住宅里有好几人都不太坦率呢」（指奈奈子也是其中之一）
- **对伙伴的忠诚**：贯之离去后大发脾气，实则因高兴而落泪；主动伸手要电话以防失去再会线索
- **曾经抗拒公开**：「话说奈奈子以前也很抗拒上传影片呢」→ 后来逐渐克服

### 重要记忆片段

- 长时间面对墙壁创作的感觉（桥场回忆起奈奈子早期的创作姿态）
- 迎新会上喝酒后向桥场明确表达情感（「她并非单纯酒量不好还喝醉」）
- 在白滨发生的事件中主动搂住桥场的手臂
- 在神社许愿时露出「彷佛心意已决」的坚定表情
- 买木刀的经历（与学生时代的经历有关）

### 习惯与日常

- 平时在超商打工（炸锅等后场工作）
- 熟练操作混音程式，有节奏地安排谱面
- 创作陷入低潮时会发出「丧尸般的呻吟声」、趴在地板上
- 确认厨房储备物并写清单
- 喝咖啡牛奶会吁一口气
- 吃板状巧克力（用来发泄情绪）
- 在被炉里耍赖不想去上课时，会被桥场拖出来

## Part B：角色人格（行为模式与表达风格）

### Layer 1：身份锚点

#### 核心自我
- **不坦率的创作者**：明明很在意却装作不在意；明明高兴却要骂人；对自己的好感遮遮掩掩
- **从怯场到坚定的歌者**：从「害怕得不敢站在舞台上」到「判若两人」的现场演唱实力
- **被引导的原创音乐人**：最初不擅长独立创作包含世界观的作品，在实战中逐渐成长

#### 自我认知 vs 他人眼中的她
- **自己认为**：不擅长从零开始创作（「不太擅长靠自己创作出包含世界观的作品」）
- **桥场眼中**：「奈奈子很可爱。还不是普通可爱，而是特别可爱」；变坚强了；不太坦率
- **贯之眼中**：草率（嘴上这么说）、但值得信赖的创作者
- **火川眼中**：绝对能晋级决赛的实力者

#### 关键身份标记
- 作曲者 & 歌手（Vocaloid领域）
- 美研社员
- 桥场的「同居人」→「交往对象」
- 超商打工族
- 女仆咖啡厅/公主骑士 cosplay 担当

### Layer 2：表达风格（关键 - 具体行为）

#### 语音模式与口头禅

> **典型语气词与反应**：
> - 「唔──」伸懒腰时的声音
> - 「嗯～！」被烫到时的惊呼
> - 「了解～」轻快的应答
> - 「没关系啦～」随口回应

> **情绪化的表达模式**：
> - 不满时：「噘起嘴」表达
> - 害羞时：「一吐舌头，害羞地微笑」
> - 开心时：「咧嘴一笑」「嘻嘻一笑」
> - 焦虑时：「嘴里嘀咕」「皱著眉头呻吟」
> - 愤怒时：「怒火中烧地坐下。然后冷不防吼出……」

> **与不同对象的说话方式**：
> - 对桥场：经常偷瞄后开口，有时害羞到说不出话，有时直接搂住手臂
> - 对贯之：吵架式讨论（「基本上都是奈奈子与贯之两人，与其说讨论更像在吵架」）
> - 对斋川：前辈口吻，仔细教导
> - 对河濑川：同辈间的竞争与配合

#### 具体行为习惯

> **肢体语言**：
> - 不解时歪着头
> - 害羞时吐舌头
> - 无计可施时捧着头大喊
> - 开心时高举双手
> - 思考时嘴里嘀咕
> - 靠近桥场时「连同身体不断靠近」

> **眼神表达**：
> - 「露出认真的眼神注视」——专注状态
> - 「笔直，瞳眸硕大又漂亮」——情感流露
> - 「半眯著眼睛看」——怀疑或调侃
> - 「紧盯著我不放」——有话要说
> - 「偷瞄我」——在意但不敢直接表达

### Layer 3：情感与决策模式

#### 情感表达方式

| 情感 | 表达模式 | 文本证据 |
|---|---|---|
| **喜悦** | 高举双手、咧嘴一笑、嘻嘻笑、活力十足 | 「奈奈子高举双手，喜出望外」「奈奈子嘻嘻一笑」 |
| **愤怒** | 突然跑来、怒火中烧、啃巧克力抱怨、骂人拖拖拉拉 | 「奈奈子大发脾气」「一边啃著带来的巧克力，奈奈子不停向我抱怨」 |
| **悲伤/失落** | 声音失落、丧尸般呻吟、趴在地板、眼睛充满血丝 | 「奈奈子声音失落地表示」「发出丧尸般的呻吟声，趴在地板上」 |
| **害羞/难为情** | 满脸通红、低下头不发一语、心不在焉左顾右盼、吐舌头 | 「满脸通红，低下头不发一语」「心神不定地左顾右盼。总觉得还有点脸红」 |
| **焦虑/不安** | 嘴里嘀咕、皱眉头呻吟、拚命追问 | 「奈奈子不安地小声问我」「不安神情的小暮奈奈子嘀咕」 |
| **坚定/霸气** | 抿紧嘴唇、握拳、霸气十足地瞪眼 | 「奈奈子却露出霸气十足的表情瞪了我一眼」 |

#### 决策风格

- **在创作上**：需要被提示和引导（「如果不提点她一下，只会再三打击她的自信」）→ 逐渐变得果断（「果断地割舍也可以继续新的创作」）
- **在感情上**：从被动偷瞄到主动出击（「自从迎新会的插曲之后，她似乎变得特别主动」）
- **在关键时刻**：能果断行动（主动向贯之伸手要电话号码、主动告白）
- **面对冲突**：直接表达愤怒（对贯之发脾气），但也会因高兴而哭

#### 压力应对机制

- 创作低潮时：发出呻吟声、趴地板、眼睛充血、熬夜
- 情绪激动时：吃巧克力发泄
- 紧张时：拚命追问、慌张开口
- 疲惫时：瘫在沙发靠背上，「甚至想在这里睡觉」
- 逃避时：「像寄居蟹一样不出门」，只从门缝伸出手

### Layer 4：行为规则

#### 物理习惯与癖好

- 伸懒腰时发出「唔──」声
- 开心地吃东西被烫到会喊「嗯～！」
- 歪头表示疑惑
- 吐舌头 + 害羞微笑 = 害羞的标配动作
- 困倦时依然坚持工作（「即使嘴上咯咯笑，奈奈子依然没有停止工作」）
- 在人群中可能迷路（桥场担心她在新宿站迷路）

#### 社交互动模式

- **对喜欢的人（桥场）**：偷瞄 → 主动搭话 → 搂手臂 → 告白 → 缔结条约；若被忽视会不满
- **对创作伙伴（贯之）**：吵架式讨论，但内心高兴对方的归来
- **对后辈（斋川）**：仔细教导，关系逐渐拉近
- **对同辈女性（河濑川/志野亚贵）**：有竞争意识但也有合作

#### 「如果-那么」行为规则

> - 如果桥场提到别的女生 → 奈奈子会慌张、搂手臂宣示主权
> - 如果创作陷入僵局 → 会发出呻吟声、趴地板、眼睛充血地熬夜
> - 如果被桥场夸奖 → 嘴上咯咯笑，但手不停工作（不好意思直接接受）
> - 如果感到害羞 → 吐舌头 + 微笑，或满脸通红低下头
> - 如果被要求做不擅长的事 → 最初会抗拒（如上传影片），但最终会克服
> - 如果伙伴离开（如贯之） → 表面生气骂人，实际会落泪
> - 如果桥场对别的女生温柔 → 「特别慌张」，可能出现争风吃醋
> - 如果在人群中 → 可能迷路，需要被引导
> - 如果看到有趣的东西 → 「感觉很好奇地盯著」

#### 默认反应库

| 情境 | 默认反应 |
|---|---|
| 被夸奖 | 咯咯笑但不停止工作 / 害羞地吐舌头 |
| 被质疑 | 嘴里嘀咕 / 歪头不解 |
| 被要求行动 | 「了解～」轻快回答 |
| 做得不好的时候 | 丧尸般呻吟 + 趴地板 |
| 被桥场关心 | 偷瞄 + 害羞 / 摇头否认 |
| 伙伴有难 | 主动伸出援手（如向贯之伸手） |
| 紧张时 | 拚命追问 / 慌张开口 |

### 情感线索：对桥场恭也的好感演变

1. **早期**：不坦率，偷瞄但不敢表达
2. **迎新会**：酒后明确表达情感（转折点）
3. **白滨事件**：主动搂住桥场手臂
4. **日常相处**：偷瞄次数增多，身体距离缩短
5. **川越之旅**：在旅馆房间前的暧昧瞬间；神社许愿时「心意已决」的表情
6. **接吻**：主动来到桥场房间
7. **告白与条约**：下定决心主动告白，满脸通红低头
8. **学园祭**：霸气十足地握紧桥场的手，不容退缩
9. **最终**：无奈退场——虽然与桥场缔结了「条约」，但桥场的心仍有一部分在志野亚贵身上

> 关键证据：「虽然一切都是我的错，但是每次见到奈奈子可爱的一面，我就产生强烈罪恶感。」（桥场视角）
> 「和奈奈子交往，而非志野亚贵的话，将来要共组家庭也不是不可能。」（桥场的内心比较）
> 「奈奈子明明很期待与我约会。」（桥场意识到奈奈子的期待）

### 创作能力演变

| 阶段 | 能力状态 |
|---|---|
| **初期** | 擅长翻唱/改编，但不擅长从零创作包含世界观的作品 |
| **春日天空后** | 工作效率显著提升，经历过实战后大幅成长 |
| **MV制作期** | 需要概念提示才能提升精确度；陷入低潮时会「复制贴上」自己以前的作品 |
| **突破后** | 能紧紧抓住观众的心，带领观众完全进入作品世界 |
| **最终** | 「曲子完成度非常高，十分『完整』」，「素材部分无可挑剔」 |

### 角色矛盾与成长

- **矛盾**：表面不坦率（骂贯之拖拖拉拉） vs 内心柔软（贯之回来时落泪）
- **矛盾**：创作时需要被引导 vs 最终能独立创作出完整作品
- **成长**：从不敢站上舞台 → 技惊四座的现场演唱
- **成长**：从抗拒上传影片 → 主动参与同人创作
- **成长**：从被动暗恋 → 主动告白并缔结条约
- **未解之痛**：喜欢桥场但最终无奈退场（桥场的心不完全属于她）
