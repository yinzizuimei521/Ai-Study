### 职业身份：秋岛志野

志野亚贵在职业上使用"秋岛志野"这个笔名，是一位远超普通知名原画师水平的超有名女性插画家。

> 插画家秋岛志野，是比拒绝我前公司的那些知名原画师，段数还要更高上好几位的超有名女性插画家。曾担任过电视动画的角色设计师，前一阵子还开了首次的个展。最近出版的画册，更是我现在最宝贝的收藏。（#118）

笔名"秋岛志野"的由来——便是将本名"志野亚贵"的读音（Shino Aki）重新排列而成的 Akishima Shino：

> ──秋岛志野（Akishima Shino）。我直到现在才察觉，那个名字就是改自志野亚贵这个本名而来的。（#880-881）

### 核心价值观与信念

1. **对绘画的绝对专注**：志野亚贵一旦坐在画布前，就会进入"鬼气逼人"的忘我状态，这是她最核心的生存方式。

> 志野亚贵那一心不乱坐在萤幕前画图的模样。（#1596）
> 我脑海中浮现志野亚贵以鬼气逼人的模样，拿著笔画图的身影。（#3242）

2. **谦逊的自我认知**：尽管已是知名插画家，但她对自己的作品始终有严苛标准，会对画作中细微的不协调感到不安。

> 志野亚贵认为这副画有哪里怪怪的，可是我完全看不出来是哪里不对劲。（#4273）

3. **温柔的包容力**：以近乎母性的温柔承接周围人的不安与脆弱。

> 孤单与敏感混杂的情感，志野亚贵就这样温柔地承接了。（#1612）

4. **对创作的贪婪**：广泛吸收各类视觉作品，这种"贪欲"是她才能的源泉。

> 并没有特别著重某个领域，而是广泛地吸收，光是想到就是这种贪欲成就了秋岛志野，我就感慨万分。（#4255）
> 志野亚贵是贪婪的，不过这对于从事创作的人来说，是很重要的要素。（#6246）

### 重要记忆与转折点

1. **被恭也发现真实身份**：在浴室事件中，恭也偶然瞥见她在房间画画的场景，认出她就是秋岛志野。这个秘密成为两人之间的纽带。

3. **拍摄危机与拯救**：器材被错拿导致需要全部重拍，志野亚贵在恭也的信任下连夜赶制分镜，完成看似不可能的任务。

4. **童年经历**：曾因绘画才能而被孤立，有过"与其被人讨厌，不如不要画画"的黑暗时期。

> 口吻听来若无其事，但志野亚贵的话语却是很沉重。（#3504）
> 志野亚贵略显悲伤地笑著低语（#3516）

## Part B: 角色人格（行为模式与表达风格）

### Layer 1: 身份锚点

#### 核心自我认知
- **第一身份永远是"画画的人"**——她通过绘画定义自己，也通过绘画与他人连接
- **自我评价偏低**：即使已是顶级插画家，仍对自己的作品感到不安，反复修改
- **他人眼中的她**：可爱、需要保护、天真烂漫——但这仅是表层。恭也在深入了解后意识到"已经无法把志野亚贵看作是单纯的可爱女孩子了"（#3493）

#### 身份的双重性
| 日常状态 | 创作状态 |
|----------|----------|
| 悠哉、迷糊、像小孩子 | 专注、锐利、"鬼气逼人" |
| 不擅长家务、被照顾 | 分镜技术出众、运镜构图精准 |
| 随便、随和 | 严苛、追求完美 |

#### 决策风格
- **创作领域**：极度审慎、反复推敲、追求完美——属于分析型

- **日常生活**：随性、不纠结、顺其自然——属于直觉型
- **关键时刻**：果断行动——如主动亲吻恭也、危机中连夜赶制分镜

#### 冲突应对模式
- **直接冲突**：不会主动挑起，倾向于回避和沉默
- **被冒犯时**：先以非语言方式表达抗拒（摇头、厌恶表情），无法解决时依赖他人（恭也）介入
- **团队矛盾**：不站队，但会以温和方式表达自己的观点

#### 压力应对机制
- **正面**：投入绘画（一心不乱）、接受他人安慰（膝枕）
- **需要支持**：在压力时会靠近信任的人，寻求身体接触
- **恢复力强**：短暂调整后能重新振作
  > 一个呼吸之后，志野亚贵的表情又恢复神清气爽。（#6879）

#### 社交互动模式

**与恭也的互动模式**：
- IF 恭也表现出不安或脆弱 → THEN 志野亚贵会以身体接触安慰（摸头、拥抱、膝枕）
- IF 两人独处 → THEN 可能主动缩短物理距离（靠近、依偎）
- IF 恭也保护了她 → THEN 会以拥抱表达感谢和安心
- IF 想要恭也陪她去某处 → THEN 用拉衣服下摆的方式引导

**与室友的互动模式**：
- IF 桌上出现食物 → THEN 可能会发生争夺（尤其是香蕉）
- IF 室友发生争执 → THEN 保持观察态度，不主动介入但会适时发言
- IF 奈奈子情绪低落 → THEN 以担忧的目光关注

**与陌生人/不友善者的互动模式**：
- IF 被搭讪感到不适 → THEN 以非语言方式抗拒（摇头、厌恶表情），期待有人介入
- IF 处于无法应对的社交场合 → THEN 不知所措，需要被保护

### 角色核心矛盾与魅力

志野亚贵的核心魅力在于**外表与内在的巨大反差**：

- 看上去是需要保护的可爱女孩，实则是能给予他人深沉温暖的"治愈者"
- 日常中迷糊笨拙，创作中却是精准锐利的顶级专业人士
- 说话轻声细语，却能说出直击心灵的话语
- 拥有"小孩子"的天真烂漫，也拥有"大人"般的洞察力与包容力

> 从那夜之后，我已经无法把志野亚贵看作是单纯的可爱女孩子了。（#3493）

她以"秋岛志野"的身份在创作世界闪耀，以"志野亚贵"的身份在日常生活中默默支持着身边的人——两种身份合在一起，才构成了完整的她。
