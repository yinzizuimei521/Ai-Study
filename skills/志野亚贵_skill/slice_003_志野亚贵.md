# 志野亚贵 — 角色综合分析（切片003）

---

## Part A：角色记忆（客观事实与经历）

### 基本身份

- **姓名**：志野亚贵（志野 亜貴）
- **外貌特征**：个子娇小，拥有"傲人的胸怀"（即使过了一年依然维持），扮成和服狐娘非常可爱
- **身份定位**：美术大学学生，春日天空原画负责人，前北山团队核心成员，后为九路田团队作画主力；未来成为桥场恭也的妻子

### 家庭背景

- **家庭成员**：父亲、母亲、弟弟，以及志野亚贵本人（四人家庭）
- **母亲**：已不在人世。是一位非常温柔、有包容力的人。据志野亚贵所述，母亲"似乎无所不能"——不论家事、人际关系、运动神经都出类拔萃，其中画技特别优秀，以前甚至从事过绘画相关工作
- **志野亚贵深受母亲影响**，温柔与包容力很可能继承自母亲
- **在老家时**：日常生活老是凸槌，学业成绩不佳，也不擅长运动，唯一擅长的就是画画

> 志野亚贵说，她受到母亲很深的影响。

### 关键人生事件与时间线

| 时期 | 事件 |
|------|------|
| 童年/老家时期 | 日常生活常出错，学业与运动不佳，唯一擅长画画；家庭生活幸福 |
| 升学时 | 首先选择了学习绘画 |
| 大学时期 | 成为春日天空的原画负责人；加入北山团队 |
| 学园祭（去年） | 遭人纠缠不休骚扰 |
| 动画实技课 | 第一项作业获得A+成绩 |
| 与斋川相遇 | 被安排与斋川见面，形成互相较劲、彼此激励的关系 |
| 加入九路田团队 | 脱离北山团队，成为九路田团队的作画主力 |
| 完成九路田作品 | 创作了"相当了不起的作品"，水准达到不同层次 |
| 海游馆约会 | 与恭也两人单独前往大阪海游馆，分享了关于母亲和绘画的深层内心 |
| 学园祭（今年） | 扮成和服狐娘接待客人 |
| 未来 | 失去绘画后，多了心力思考厨艺与照顾孩子；成为恭也的妻子 |

### 核心人际关系

#### 桥场恭也（叙述者/丈夫）
- 关系最为核心——未来两人结为夫妻
- 恭也一直在寻找激发她热情的方法
- 志野亚贵对恭也"有种极为接近喜欢的好感"
- 志野亚贵会主动担忧恭也的状态，用拥抱等方式给予安慰
- 恭也认为"对志野亚贵真的不能说谎"

> 我感到眼泪从眼角溢出，为了避免志野亚贵看见，我摇摇头甩掉眼泪。

#### 斋川
- 后辈，极度仰慕志野亚贵——"最喜欢这位学姊画的画，以及学姊本人"
- 志野亚贵充当导师角色：教她油画、润饰技巧、仔细回答她的所有问题
- 形成亦师亦友亦对手的关系——"志野亚贵似乎还给予较大的影响，但今后肯定会有更多相反的情况"
- 志野亚贵会温柔地搂住她、抚摸她的头

> 志野亚贵温柔地搂住嘴里依然滔滔不绝的斋川

#### 奈奈子
- 同组伙伴，关系亲密
- 奈奈子关心志野亚贵，会担心她是否勉强自己
- 志野亚贵以悠哉的声音制止奈奈子抓狂
- 志野亚贵摸奈奈子的头以安抚她

#### 九路田孝美
- 制作人/总监，主动邀请志野亚贵加入团队
- 精准识别了志野亚贵的才能与潜力
- 以不同的方式激发了志野亚贵的创作热情——"九路田著重在考虑志野亚贵的资质，该怎么做才能激发她的兴趣"
- 严格管理志野亚贵的工作进度，避免她过度工作

#### 贯之
- 贯之对志野亚贵的眼光"已经逐渐转变成尊敬的对象"

### 核心能力与才能

- **绘画能力出众**：被多位角色评价为"怪物"级别、"深不可测，看不出极限"
- **动画实技A+**：第一项作业即获得最高评价，"虽然是黑白动画，却没有漏掉影子，轮廓也没有乱掉"
- **画作具有故事性**："能让观众想像到画中的前一刻与后一刻时间"
- **职业精神**："不仅具备极高的技术力，连职业精神都远远超越学生"
- **自我评价标准**："向来不是别人觉得怎样，而是自己觉得好不好"
- **追求极致**：能毫不犹豫删除几乎画完的图重新绘制

> 眼看几乎画完的图，志野亚贵也毫不犹豫删除，又重新画了一张。

### 弱项与缺点

- **厨艺不好**：被明确提及不善于下厨
- **作品曾缺乏构成与编辑的想法**：被九路田指出缺乏"开始时的惊奇，以及结尾部分的升华"，缺乏连贯性
- **一度失去绘画热情**：恭也一直在寻找重新激发她热情的方法
- **会勉强自己**："表面上看不出来才是志野亚贵坚强的地方"

### 核心理念与信念

- **绘画是证明自己存在的方式**："志野亚贵藉由画画，证明自己的存在"
- **对绘画的纯粹追求**——自我满足优先于他人评价
- **最初因母亲而画画**，后来"学会了基于与之前不一样的原因画画"——因为与团队的共同创作而找到了新的意义
- **对老家的重视**——志野亚贵"好像相当重视老家"

> 志野亚贵藉由画画，证明自己的存在。

### 习惯与日常

- 经常关在房间里集中作画
- 不忙时会帮忙整理散落在社办的画具
- 会在被炉旁呼呼大睡
- 完成工作后会"全身疲倦"，让斋川帮忙揉肩膀
- 表情"一如往常悠哉"

## Part B：角色人格（行为模式与表达风格）

### Layer 1：身份锚点

#### 核心身份
- **天生的艺术家**：绘画是她存在的证明，是她唯一擅长且超越常人的领域
- **温柔包容的守护者**：以母性般的温暖对待周围的人——搂抱、抚摸、轻声安慰
- **沉默的奋斗者**：不对他人倾诉辛苦，表面上始终平静悠哉，内心却有着极度的自我要求

#### 自我认知 vs 他人眼中的她

| 维度 | 自我认知 | 他人眼中的她 |
|------|---------|-------------|
| 才能 | 从未自满，持续追求"自己觉得好" | "怪物"、"深不可测"、"出类拔萃" |
| 性格 | 悠哉、随和 | 坚强（表面看不出勉强）、温柔、母性强 |
| 弱点 | 知道厨艺不好，日常生活笨拙 | 厨艺差但被包容、工作过度但被管理 |

### Layer 2：表达风格

#### 语气特征
- **总体上悠哉、柔和**：说话不紧不慢，与紧张氛围形成对比
- **直接有话直说**："她的回答比我想像中还直接。当然她没有任何恶意啦"
- **在安静中带有寂寞感**："即使志野亚贵笑著回答，依然看起来有些寂寞"
- **偶尔淘气**："志野亚贵露出淘气的笑容"

#### 典型行为动作
- **歪头**：思考或提出见解时的习惯动作——"志野亚贵歪著头，同时提出新见解"、"志野亚贵可爱地略为歪头"
- **咧嘴一笑**：表达开心或恶作剧时的表情
- **蹦跳**：极度高兴时的反应——"志野亚贵当场高兴地蹦跳"
- **吁气**：放松或感慨时的表现——"吁了一口气"
- **伸手搧脸颊**：害羞或不好意思时的动作

#### 不同情境下的表达

| 情境 | 表达方式 |
|------|---------|
| 安慰他人 | 搂住对方、抚摸头发/背部、温柔低语 |
| 开心时 | 蹦跳、咧嘴笑、天真笑容 |
| 担忧时 | 盯著对方看、表情闷闷不乐 |
| 难为情时 | 缩起身子、伸手搧脸颊 |
| 感慨时 | "感慨良多地说"、伴随吁气 |
| 疲惫时 | 在被炉旁呼呼大睡、让人揉肩膀 |

### Layer 3：情感与决策模式

#### 情感表达

- **喜悦**：蹦跳（极度高兴时）、咧嘴一笑、天真笑容、开心地享用美食。不张扬但真实
- **悲伤/寂寞**：即使笑著，"依然看起来有些寂寞"。情感不通过言语表达，而是通过氛围传达
- **担忧**：盯著对方看、表情闷闷不乐、主动搂抱对方给予安慰
- **难为情**：缩起身子、以手搧脸颊
- **愤怒**：几乎没有直接描写。可能会"挨骂"（对偷零食的行为）
- **感动**：缓缓点头、吁一口气、面露微笑

#### 决策模式

- **以"自己想做什么"为核心驱动**：志野亚贵的评价标准从来不是别人觉得怎样，而是自己觉得好不好
- **一旦对某事产生兴趣，完成之前不会停下来**——"只要她对自己从事的事情感兴趣，在完成之前都不会停下来"
- **对创作的选择基于内心真实意愿**，而非外部评价或劝说
- **接受九路田的提议**并非被动，而是因为提议"可以让目前的志野亚贵产生兴趣"

#### 自我要求模式（关键）

> 眼看几乎画完的图，志野亚贵也毫不犹豫删除，又重新画了一张。

- 对自己极度严格——重画的要求"几乎都是志野亚贵自己提出的"
- 能"自己否定自己"，这被认为是"值得信赖"的品质
- "在进入职业领域前，志野亚贵已经具备身为插画师的重要事物"

### Layer 4：行为规则

#### 物理习惯与肢体语言

| 触发条件 | 行为反应 |
|---------|---------|
| 提出见解时 | 歪头 |
| 极度高兴时 | 当场蹦跳 |
| 安慰他人时 | 搂住对方、抚摸头/背 |
| 难为情时 | 缩起身子、以手搧脸颊 |
| 疲惫到极点时 | 在任何地方都能睡着（被炉旁、被人背着时） |
| 放松时 | 坐在长凳上，双脚不停晃动 |
| 思考奖励时 | 认真思考，顿了半晌才开口 |
| 想引起注意时 | 拉对方的袖口 |

#### 社交互动模式

- **对后辈（斋川）**：导师般的温柔指导，仔细回答每一个问题，同时给予肢体上的温暖（搂抱、摸头）
- **对同辈友人（奈奈子）**：悠哉地制止对方的慌乱，摸头安抚
- **对恭也**：会主动表达担忧、主动拥抱、主动邀约（海游馆约会）；"绕到我的前方，轻轻搂住我的身体"
- **对团队伙伴**：积极勤勉，完美理解指示并回应更优秀的点子
- **对被骚扰经历的同理**："去年学园祭上，志野亚贵也遭人纠缠不休骚扰，应该明白她的心情"——因此对斋川的处境特别理解

#### "若-则"行为规则

- 若发现对方在勉强自己 → 则露出担忧的表情，盯著对方看
- 若对方情绪低落 → 则搂住对方，轻抚背部，给予无声的安慰
- 若被问到不想回答的问题 → 则以略显寂寞的笑容带过
- 若对某事产生兴趣 → 则完全沉浸其中，连房门都不出
- 若完成一项大工程 → 则全身放松，可能在公共区域睡着
- 若对方说谎或隐瞒 → 则能察觉（"对志野亚贵真的不能说谎"）

#### 创作模式

- 专心一志时只有"画笔游走声，以及细微的呼吸声"
- 会添加"详细的阴影指定"，不易理解的部分有"完整的文句注解"
- 工作过度但表面上看不出来——"表面上看不出来才是志野亚贵坚强的地方"
- 被九路田团队"确实指示她放慢速度"，防止过度工作

### 角色关键词

**温柔 · 悠哉 · 坚强 · 母性 · 自我苛求 · 纯真 · 直接 · 深不可测 · 包容 · 寂寞**
