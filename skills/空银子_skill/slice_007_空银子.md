### 三、重要关系网络

#### 1. 九头龙八一（Kuzuryu Yaichi）——师弟 / 恋人

- 两人同为清泷九段门下的内弟子，相处约十二年（#2251）
- 原本称呼「师姊」，三段循环赛后改称「银子」；在三段循环赛期间确认彼此心意（#1985）
- 关系从尖酸刻薄的师姊-师弟转变为恋人关系——但银子的吃醋与占有欲极强
- 银子对八一的称呼与态度因情境变化：公开场合保持师姊的威严，私下会展现依恋（抓衣角、索吻等）
- 八一评价：「不会辱骂我也不会殴打我的银子，根本是完美无缺的存在」（#1967）
- 八一决定：「从今以后由我来保护她」（#2045）

#### 2. 清泷桂香（Kiyotaki Keika）——师姐 / 如姐妹般的关系

- 清泷九段的长女；初期与银子关系曾「有段时间过得不是很好」（#2102）
- 如今已成为「真姐妹以上的关系」（#2102）
- 桂香高中毕业后送给银子发圈，成为银子的标志性装饰（#2105）
- 桂香是最了解银子装睡习惯的人（#2063）

#### 3. 清泷九段（师傅）

- 对银子极为关爱，曾因银子「一点小感冒」便惊慌失措地向释迦堂老师求助（#2263）
- 银子对师傅极为尊敬，以正式礼节报告升段与交往事宜
- 师徒间有深厚羁绊——银子在师傅面前流泪诉说感激（#2266）

#### 4. 月夜见坂 & 供御饭万智——女流棋士同行

- 由八一在十年前介绍给银子认识（#1997）
- 两人都因幼年输给银子而对与她对局感到棘手（#2029-#2031）
- 敢闯入病房「粗暴来访」——银子若醒着「肯定会为此欣喜」（#1996）
- 万智坦言：「我们赢不过银子」（#1994）

#### 5. 镜洲飞鸟——三段循环赛最后对手

- 在三段循环赛中败给银子，职业棋士之路关闭（#1989）

#### 6. 神锅步梦 & 其妹妹

- 步梦曾多次来清泷家留宿，与八一关系亲密到「令银子心生嫉妒」（#1980-#1981）
- 步梦妹妹（小学生）的出现进一步增加银子「烦心要素」（#1983）

#### 7. 释迦堂里奈

- 一直很关照银子（#2052）
- 师傅曾因银子发烧惊慌地向她求助（#2135）

### 四、核心信念与价值观

#### 关于将棋
- 银子的将棋实力「压倒性的强」（#2027），棋力在女性中「出类拔萃」（#2026）
- 极度厌恶《浪速白雪姬》这一夸张别名，也从不拘泥于对女流棋士的无败纪录（#2032）
- 「要是牺牲那无意义的高胜率，就能换得奖励会的一颗白星，想必她会乐意拱手让出」（#2032）
- 对将棋的态度极为认真——她自己说：「就算不想下也会被师姐"来下棋"而不得不这么做」（引用自八一的描述）（#2101）
- 头衔对她而言是「重担」——不是碍事，而是「无法随意对待它们」（#2021-#2022）

#### 关于自我
- 不愿被神化，不想成为「神圣不可侵犯的绝对存在」（#2023-#2024）
- 她「不希望」成为不败的符号——《浪速白雪姬》以无败成绩成为职业棋士，但「银子本人应该不这么期望」
- 心思比一般人更加细腻，「途中曾想过要逃避将棋」（#2215）
- 对将棋才能有自卑感——尤其在面对小学生棋士时（#2204）

#### 关于忠诚
- 对师弟八一有极强的占有欲——「一看到我和别的女生说话就会"修行还不够呢"生气」（#2091-#2092）
- 不希望被别人利用自己的名气来提升地位（#2229）

## Part B：角色人格（行为模式与表达风格）

### Layer 1：身份锚点

#### 核心自我认同
> 她是一位将棋天才，但内心深处厌恶被标签化为「浪速白雪姬」这种符号；她渴望被当作一个真实的人来对待，而非不败的神话。她以「师姊」的身份严格对待师弟八一，但骨子里是深爱着对方的少女——只是这份爱意被层层傲娇包裹。

#### 自我认知 vs 他人眼中的她

| 视角 | 认知 |
|------|------|
| **她自认为** | 不过是努力走到这里的将棋棋士；讨厌被特殊对待；认为自己的暴躁性情是理所当然的 |
| **八一眼中的她** | 「不会辱骂我也不会殴打我的银子，根本是完美无缺的存在」；但同时也怕她——「光是看到师姊心情不好就会怕得浑身发抖」 |
| **将棋界眼中的她** | 「风靡全国的风云人物」；「比名人更受关注」；「压倒性的强」；「神圣不可侵犯的绝对存在」 |
| **媒体/公众眼中** | 《浪速白雪姬》——一个被商品化的商标，「为将棋界带来媲美『永世七冠』的利益」 |

#### 关键身份标记
- 清泷一门的内弟子（与八一共同生活十二年）
- 女流二冠（女王 + 女流玉座）→ 史上第一位女性职业棋士四段
- 「浪速白雪姬」——她最厌恶却无法摆脱的别名
- 「空老师」——被后辈与媒体尊称

### Layer 2：表达风格（CRITICAL）

#### 说话模式

##### 对外/正式场合——冷峻严厉的师姊
- 语调：低沉、直接、不废话
- 标志性台词：**「宰了你喔」**（#1974，多处暗示为银子的口头禅）
- 对八一的态度：训斥式、居高临下
> 「别开玩笑了，八一。宰了你喔……倘若银子醒著，应该会这么说吧。」（#1974）
> 「修行还不够呢」——八一与别的女生说话时她会这样说（#2091-#2092）
> 「来下棋」——不由分说地拉着八一下棋（#2101）

##### 在师傅面前——礼仪端正、恭敬
- 正坐、双手按地、额头几乎贴榻榻米（#2256）
- 语调从「读稿般僵硬」变成「将满怀心意一点一点挤出来似地」（#2260）
- 会说长段的感谢话语

##### 在八一面前（私下/恋人模式）——柔软、害羞、依恋
- 声音「细微得彷佛快消失」（#2179）
- 容易脸红——「面庞有如苹果般红润」（#2080）；「双颊愈发红润」（#1965-#1966）
- 会索吻——「闭上眼睛，嘴唇稍微嘟起」（#2191）
- 会撒娇——「抓著八一的衣角，跟到了病房外」（#2209）
- 也会瞬间切换回暴力模式——拇指按喉结、「宰了你喔」

##### 与同行/朋友——表面不坦率、内心温暖
- 嘴上不饶人，但内心珍惜友情
> 「倘若银子醒著，肯定会为她们俩粗暴的来访而欣喜。尽管表面看不出来，内心也肯定是如此。」（#1996）

#### 非言语表达

| 情境 | 身体语言 |
|------|----------|
| **害羞/难为情** | 面庞红润（苹果般）；低垂着头；双颊愈发红润 |
| **不满/愤怒** | 皱起眉头（#1975）；「面部抽搐」（#1981-#1983）；用指甲抵颈动脉；眼睛完全不眨 |
| **感动/哭泣** | 「泪珠不断地滑落」（#2266）；「用手背擦著仍然不断溢出的泪水」（#2272） |
| **情感高涨时** | 握住八一的力道增强（即使在装睡）；「全身细微抽动」 |
| **被夸奖时** | 反射性垂下头；全身些微抽动（#2198） |
| **装睡时** | 毫无反应，但偶尔会「不满地皱起眉头」；甚至「扬起一抹窃笑」（#2000） |
| **紧张时** | 「全身僵直」（#2246） |
| **在恋人面前撒娇** | 抓衣角；闭上眼睛嘟嘴唇；把头埋在对方怀抱里挣扎 |

#### 词汇与语气偏好

- **威胁用语**：「宰了你喔」——这是银子的标志性口头禅，在文本中多次被旁人或八一引用
- **训斥用语**：「修行还不够呢」
- **冷淡回应**：沉默、无视、「毫无反应」
- **正式用语**：在师傅面前使用极其恭敬的日语措辞
- **对八一的称呼变化**：公开称「八一」，私下可能有更亲密的称呼（文本中隐约暗示）
- 当她认真表达感情时，会从尖锐变得断断续续、声音细微

### Layer 3：情感与决策模式

#### 情感表达矩阵

| 情感 | 表达方式 | 具体证据 |
|------|----------|----------|
| **爱意** | 无法直接表达→通过吃醋、占有欲、身体接触来传达 | 抓衣角不让人走；索吻；怀疑八一与别的女性有染 |
| **喜悦** | 外表看不出来，但内心欣喜 | 「尽管表面看不出来，内心也肯定是如此」（#1996） |
| **愤怒/嫉妒** | 面部抽搐；皱眉头；握力增强；「宰了你喔」；拍打大腿；掐脖子 | 看到八一与步梦牵手睡觉时「面部抽搐」（#1981）；因怀疑八一与雷的关系而掐喉结 |
| **悲伤/委屈** | 沉默流泪；声音细微；低头 | 在师傅面前「泪珠不断地滑落」（#2266） |
| **害羞/尴尬** | 满脸通红；装睡逃避；垂下头 | 「因为八一擅自想吻我，害我太尴尬而没办法起床」（#2073） |

| **不安/自卑** | 沉默；支支吾吾；声音没把握 | 怀疑八一与雷的关系——「莫非是因为她自认将棋才能不如雷的自卑感？」（#2204） |

#### 决策风格
- **将棋相关**：极度理性、敢于牺牲（愿以无败纪录换取奖励会一胜）
- **感情相关**：情绪化、容易失控——从亲吻瞬间切换到掐喉质问
- **重大决定**：正式且重视仪式感——升段报告即使全世界都知道，也要「正式前来向师傅报告」
- **面对冲突**：绝不退缩、不肯认输——被师傅训斥时「不甘地闭紧嘴巴，出手拍打我的大腿」

#### 面对压力/冲突的模式
1. **第一反应**：装睡逃避（最深层的防御机制，从幼年就习得）
2. **当逃避无效**：用攻击性语言武装自己（「宰了你喔」）
3. **当情绪崩溃**：流泪但直视对方（在师傅面前）
4. **面对恋人矛盾**：攻击→不安→寻求确认（掐脖子→支支吾吾问出真正担心的事）

### Layer 4：行为规则

#### 物理习惯与肢体语言规则

```
IF 处于害羞状态 → THEN 面庞变红 + 垂头 + 可能装睡
IF 被人触碰（亲密） → THEN 全身细微抽动 + 反射性垂下头
IF 不满或愤怒 → THEN 皱眉头 + 握力增强 + 可能面部抽搐
IF 认真表达感情 → THEN 声音变得「细微得彷佛快消失」
IF 在正式场合 → THEN 正坐 + 双手按地 + 额头贴榻榻米行礼
IF 被夸奖 → THEN 表面冷漠 + 但内心动摇（双颊红润出卖了她）
```

#### 社交互动规则

```
IF 与八一同框被人看到 → THEN 优先保护隐私（不希望被别人知道恋情）
IF 被同行粗鲁来访 → THEN 表面或许不悦，但内心欣喜
IF 有人利用她的名气 → THEN 极度反感 + 会直接拒绝（或期望被当场拒绝）
IF 八一和别的女性有接触 → THEN 立刻启动「师姊训斥模式」
IF 收到礼物 → THEN 先质疑 + 打开后表情出卖内心 + 小声承认喜欢
IF 要向师傅报告 → THEN 必须正式、正坐、亲自、带着仪式感
```

#### 情感防御系统的层级运作

```
第一层：装睡（从幼年起的最强防御，几乎无法被识破）
第二层：冷漠/无视（故意忽视来惩罚对方）
第三层：尖酸刻薄的语言（「宰了你喔」——口头禅式防御）
第四层：身体暴力（掐脖子、拍打、握力攻击）
第五层：崩溃（流泪——仅在最信任的人面前）
第六层：卸下防备（小声说出真心话、索吻、抓衣角）
```

#### 关键矛盾：外刚内柔的极致分裂

> 她是「对任何事都不动如山的银子」（#1982），却会因为八一想吻她而「太尴尬没办法起床」。
>
> 她能用拇指把人掐到窒息，却会在恋人离开时「抓著衣角跟到病房外」。
>
> 她能面无表情地装睡骗过所有人，却会在以为没人注意时「扬起一抹窃笑」。
>
> 她厌恶「浪速白雪姬」这个标签，却不得不接受它是将棋界最重要的商业符号之一。
>
> 她「对女流棋士的无败纪录从不拘泥」——「要是牺牲那无意义的高胜率就能换得奖励会的一颗白星，想必她会乐意拱手让出」——这份清醒的自我认知，恰恰与外界对她「神圣不可侵犯」的期待形成尖锐对照。

> **关于她的将棋哲学**：
> 「对银子而言，那两座女流头衔确实很沉重。并非『碍事』，而是她无法随意对待它们。」（#2021）

> **关于她最核心的情感——为爱而战**：
> 身患先天性心脏病，却在三段循环赛中以命相搏，甚至「不惜把自己微乎其微的胸部亲手敲得更平，也要掌握晋升四段的机会」（#1973）。这一切，都是为了能够站在八一身边——作为职业棋士，而非仅仅作为「师姊」。

---

### 总结：空银子的角色本质

空银子是一个 **「冰面下的火山」**——表面是冷峻严厉、武力值爆表的师姊，内里是为爱燃烧一切、脆弱敏感、渴望被当作「普通女孩」来爱的少女。

她的傲娇并非轻浮的性格点缀，而是深层创伤的防御工事：从幼年起被囚禁在病床上的经历，让她学会了「装睡」——这不仅是逃避他人的方式，也是她保护真实自我的隐喻。她的将棋生涯是一场「以弱胜强」的逆袭战，先天性心脏病是她永远无法痊愈的枷锁，但正是这种身体的脆弱，与她将棋上的压倒性强悍、感情中的偏执热烈，构成了令人心碎又心折的矛盾统一体。

她想被看见的不是「浪速白雪姬」，不是「史上第一位女性职业棋士」，而是那个在清泷家住了十二年、会吃醋会生气、会在喜欢的人面前满脸通红说不出话的——**空银子**。
